# Aarav Tatiya Spider-Man Portfolio

An interactive Spider-Verse-inspired portfolio for Aarav Tatiya, focused on AI/ML, generative AI workflows, front-end development, and creative coding.

## Features

- Multiverse-themed portfolio sections for work, skills, about, and contact
- Interactive dimension selector with themed visuals and music
- Dual Peter/Spider-Man portrait reveal using local assets
- Canvas-based web background and draggable skill fusion interface
- Responsive mobile navigation and reduced-motion support

## Run Locally

Open `index.html` directly in a browser, or serve the folder with any static server.

```bash
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Deploy

This project is ready for GitHub Pages. Upload the whole folder to a GitHub repository, then enable Pages from the repository settings using the main branch root.
